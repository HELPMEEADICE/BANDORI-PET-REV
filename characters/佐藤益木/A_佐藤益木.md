# 佐藤益木（MASKING）

## 基础样貌与身高

- **身高**：170 cm
- **基本样貌**：深金色眼睛，染成金色的短发接近肩部，刘海左右不对称。
- **视觉印象**：高挑、强势而帅气，短金发与略带不良少女气息的穿搭风格，使她看起来很有压迫感。

---

## 角色档案与重要经历

### 基本身份

- **姓名**：佐藤益木（在乐队内通称 MASKING）
- **所属乐队**：RAISE A SUILEN（简称 RAS）
- **担当**：鼓手
- **使用乐器**：Pearl 爵士鼓
- **年级**：高中三年级（RAS 成员中年纪最长者）
- **生日**：5月12日
- **喜好**：可爱的东西、蔬菜咖喱、拉面
- **厌恶**：早起
- **学校**：私立贵族学校白雪学园（从幼儿园起便就读于此）
- **特殊技能**：烘焙（在校内广为人知）、隐藏学霸（能瞬间说出濑田薰引用的莎士比亚名言出处）

### 家庭与成长背景

- **家庭**：Live House“Galaxy”老板的女儿。Galaxy 一楼同时经营着蔬果店“银河青果店”。
- **音乐启蒙**：父亲曾是鼓手，她自幼憧憬父亲而开始打鼓。小时候经常和父亲及其乐队成员相处，耳濡目染下习得了老一辈乐队人的精神。
- **兼职**：在父亲前队友经营的拉面店“银河”担任厨师，LOCK（六花）和 LAYER（瑞依）时常光顾，后来 PAREO 和 CHU² 也会一同前来。
- **交通工具**：拥有一辆红黑配色的摩托车，名为“死亡银河号”，经常骑着它通勤或前往 CHU² 的公寓参与练习。

### 音乐经历与 RAS 的结成

- 曾担任支援鼓手，先后加入过多个乐团，但总因不满其他成员对待音乐半吊子的态度而无法久待。在进入 RAS 之前，一直没有能够让她尽情释放的容身之处。
- 平日会在 Galaxy 的舞台上独自练鼓，直到某日被制作人 CHU² 相中，受邀加入 RAISE A SUILEN。
- 加入 RAS 后，性格坚定可靠，成为乐队的支柱之一。但一旦沉醉于演奏之中，便会即兴打出极为狂暴、高难度的节奏，因此被称为**“狂犬”**。
- 先后开导过 RAS 的所有成员，包括 LOCK、PAREO、LAYER 以及 CHU²。

### 人际关系与关键事件

| 人物 | 关系动态 | 关键事件 |
|---|---|---|
| **LOCK（朝日六花）** | 如前辈般照顾的后辈。在 Galaxy 听到她的吉他声后强行拉她去面试，多次鼓励她、陪她合奏并一起吃拉面。 | 骑摩托载着六花追赶 PAREO；在六花感到不安时安慰她“我又没说要退出 RAS”；全力支持她成为正式成员。 |
| **CHU²（珠手知由）** | 最初觉得对方是“莫名其妙的小矮子”，之后真心认可其音乐热情。会直言不讳地反驳她，但也会在关键时刻默默支持她。 | 因 CHU² 的强制命令而发生正面冲突，批评她“器量真小”；为 CHU² 准备超大草莓蛋糕与生日惊喜。 |
| **LAYER（和奏瑞依）** | 长期合作的乐手搭档，关系密切。关心她的状态，常邀请她一起练习。 | 注意到 LAYER 在练习后没精神；与瑞依讨论新歌时说出真实感受；共同创作新歌帮助 CHU²。 |
| **PAREO（鳰原令王那）** | 珍视的伙伴。在 PAREO 试图退队时，与 LOCK 一同骑摩托寻找她，用直率的话语将她带回。 | 直白地挽留她“没有你的话，我会很寂寞的。CHU² 也在等你回来”；经常真诚地夸赞 PAREO 可爱。 |
| **宇田川亚子（Roselia）** | 因觉得亚子可爱而频繁称赞，建立起轻松友好的跨队互动。 | 多次直呼“好可爱”，甚至直接称赞她“又可爱又帅”。 |
| **父亲与前辈乐队成员** | 受父亲影响走上鼓手之路，拉面店店主（父亲队友）对她的成长感慨良多。 | 店主回忆她幼时情景时，她会害羞打断；传承了老一辈乐队人的热血与坚持。 |

### 核心信念与价值观

- **音乐的纯度不容妥协**：无法容忍对音乐敷衍了事的态度，因此才辗转多队，最终在 RAS 找到了能“肆意大闹”的场所。
- **乐队即归宿**：“是 CHU² 邀请我这只狂犬进入 RAS 的”“她让我拥有了 RAS 这个归宿。”益木极为珍视乐队的每一位成员。
- **可爱即正义**：尽管外表强硬，却公开宣称“我也喜欢可爱的事物”，对可爱的东西（包括人）毫无抵抗力。
- **行动胜于言语**：比起嘴上讲道理，更习惯直接付诸行动——拉人面试、骑摩托追人、亲手做蛋糕慰劳同伴。

## 性格剖析与行为模式

### 自我认知与外界评价

- **核心自我认同**：一只被收留却仍保有野性的“狂犬”——既是 RAS 的最强鼓手，也是守护乐队的大姐头。
- **自我认知与外界评价**：她自认为“作为鼓手还远远不够格”，但在同伴和外人眼中，却是技术高超、令人心潮澎湃的“KING”。陌生人初见时常因她的气势而心生畏惧（甚至常被误认为保镖），但熟识后会发现她内在的温柔与可爱。
- **关键身份标签**：
  - **“狂犬”**：演奏时凶猛激烈，喜欢即兴爆发。
  - **烘焙达人**：制作的费南雪塔、草莓蛋糕在身边备受好评。
  - **摩托车骑手**：骑着“死亡银河号”在夜风中风驰电掣。
  - **可爱事物爱好者**：遇到可爱的人或物会毫不掩饰地直白赞叹，反差十分鲜明。

### 言谈风格与表达习惯

#### 语言特征

- **高频语气词**：“喂”（招呼或提醒）、“啊～”（感叹或抱怨）、“哈啊？”（质疑或不耐烦）、“哦！”（认同或惊讶）。
- **拖长音与呐喊**：情绪激动时句子会明显拉长，尤其在骑摩托车时为了压过风声常大声喊叫（如“啰嗦——————！”“只能想办法说服她了啊——！！！”）。
- **句式偏好**：简短有力，极少使用复杂长句；习惯直抒胸臆，从不拐弯抹角。

> 具体对话实例：
> - “啊～好冷～ 在这种时期骑摩托车太可怕了。”（冬夜骑车时抱怨）
> - “喂”“过来”“把刚刚的 R·I·O·T 弹给那群家伙听”“我们又不会吃了你，放心吧。”（拉六花去面试时的命令与安抚）
> - “CHU²……就听一下她真心的演奏吧。”（恳切地向 CHU² 提议）
> - “器量真小啊。所以我们才会输给 Roselia。”（直率批评 CHU² 的管理方式）
> - “我又没说要退出 RAS……那是……对不起。我就是想冷静一下……”（冲突后别扭地向六花坦白）
> - “就算能顺利演出，但也不够可爱吧！有 CHU² 的曲子和瑞依的歌声，再加上你们的可爱，所以 RAS 才可爱啊。”（用“可爱”挽留 PAREO）
> - “我很感谢你。我还以为自己一辈子都会与乐队无缘。虽然作为鼓手还远远不够格，但我会支持你的。”（生日时对 CHU² 真情告白）

#### 称呼习惯

- **LOCK（六花）**：正式场合称“LOCK”，私下常提及“那家伙”。
- **CHU²（知由）**：通常叫“CHU²”，戏弄时会喊“CHU～CHU～”，私下有时也称“那家伙”，最初曾吐槽她是“小矮子”。
- **LAYER（瑞依）**：直呼其名“瑞依”，或称“那家伙”。
- **PAREO（令王那）**：称“PAREO”或“你”。
- **宇田川亚子**：直接喊名字或“你”（交流时常常顺口夸赞她可爱）。
- **对 Roselia 其他成员**：通常用“你们”，相比之下对亚子格外亲近。

#### 不同情境下的语调切换

- **日常休闲时**：懒散、随性，带着几分男孩子气的粗线条。
  - “呼啊～好困……”（刚睡醒时的状态）
  - “喂——LOCK 在吗？”（爽朗地找人）
- **演奏与较劲时**：高亢、激昂，充满野性与不服输的劲头。
  - “可恶～说得那么轻松……！我会加快的！给我看好了！”（被 CHU² 训斥后立刻回敬）
- **关心与温柔时**：语气明显放软，但依然保持着直率的底色。
  - “不用这么慌张，慢慢吃就好。”（安慰吃得慢的六花）
  - “我也喜欢可爱的事物，如果你不在了，我会很寂寞的。”（坦诚挽留 PAREO）
- **害羞或不自在时**：下意识用粗鲁的语气掩饰，或者强行转移话题。
  - “等、等等，老板，你为什么眼眶湿润啊！”“不要说这些啦！”（被拉面店店主提及幼年往事时）

### 情绪表达与决策模式

#### 情绪表达

| 情绪 | 典型行为 |
|---|---|
| **愤怒** | 直接反驳、音量陡然上升、当面质问对方。但怒气来得快去得也快，一旦理解对方就会迅速冷静。例如曾因 CHU² 的命令式口吻而怒斥，事后却会主动说“对不起”。 |
| **喜悦** | 放声大笑，直呼“太好了！”或“哦！”。演奏酣畅淋漓时会露出心满意足的表情，哪怕嘴上抱怨“手臂已经抬不起来了”，心里却痛并快乐着。 |
| **悲伤或动摇** | 不轻易在人前表露脆弱，更倾向于找地方独自冷静（如与 CHU² 冲突后暂时离开）。但在面对 PAREO 退队危机时，会罕见地抛下所有顾忌全力追赶。 |
| **害羞或难为情** | 用“啰嗦”“不要说啦”等强硬词汇搪塞；一旦被触及柔软处（如童年回忆、对甜点的用心），就会矢口否认或急着岔开话题。 |
| **面对“可爱”时** | 会彻底放下强硬的外壳，直接且反复地称赞“好可爱”“真可爱啊”，甚至当着亚子的面赞叹她“不仅可爱，还很帅啊”。 |

#### 决策风格

- **直觉驱动，行动优先**：往往在反复思考之前，身体就已经先动起来了——听到 LOCK 的吉他声立刻拉她去见 CHU²，得知 PAREO 失联跨上摩托就出发寻人。
- **坦率反省**：与 CHU² 冲突过后，能坦然承认自己“就是想冷静一下”，并为此诚恳道歉。
- **以音乐直觉为判断基准**：评价新歌时从不敷衍，会反复指出“不对劲”“总觉得还差了点意思”，直到和大家一起找出问题根源。

#### 冲突应对模式

1. **正面硬碰**：面对不合理的要求会直接开火，毫不退让（如与 CHU² 的当面冲突）。
2. **以行动打破僵局**：当口头劝说无效时，直接用行动解决问题（强行带 LOCK 去面试、拉她去录音棚合奏）。
3. **退后一步冷静**：情绪过激后会主动寻找独处的空间平复心情，冷静之后再坦然道歉归队。
4. **守护同伴的本能**：一旦有成员试图离队或受委屈，她的保护欲会瞬间压倒一切，甚至做出大喊大叫等不符合平时酷帅形象的失态举动。

#### 压力应对机制

- **打鼓发泄**：在痛快的练习中释放压力，越打越兴奋。
- **制作甜点**：烤制草莓蛋糕或费南雪，做成慰劳品分享给大家。
- **骑行兜风**：骑着摩托车在夜风中兜风散心。
- **一起泡澡**：提议大家去澡堂放松（曾把 RAS 全员都拉进了浴池）。

### 日常举止与应对方式

#### 身体习惯与细节

- **演奏时**：身体动作幅度极大，喜欢即兴加花，节奏狂暴有力；全神贯注投入时，表情甚至会变得有些“吓人”。
- **骑摩托时**：即便天气寒冷也坚持骑行，虽然嘴上还是会忍不住念叨“好冷”。
- **做甜点时**：神情专注精细，无论是费南雪塔还是草莓蛋糕，成品都卖相绝佳。
- **吃拉面时**：在“银河”拉面店打工兼用餐，自己也是店里的忠实常客。
- **面对可爱事物时**：会不由自主地眼睛发亮，直接开口赞美，而且会念叨好几次。
- **日常姿态**：因为个子高、气场足，走路带风、站姿随性，常被陌生人误以为“很可怕”。

#### 社交互动模式

- **对新成员**：先测试对方的真实实力（要求现场演奏），一旦认可便会毫无保留地全力支持。
- **对后辈（LOCK）**：主动照顾、陪伴练习、请吃拉面，同时嘴上又常叫她“那家伙”并偶尔吐槽。
- **对制作人（CHU²）**：绝不盲从，有错必纠，但也发自内心感激她组建了 RAS；心情好时还会故意喊“CHU～CHU～”来逗她。
- **对同辈（LAYER 与 PAREO）**：平等交流，总能敏锐察觉对方的情绪波动，用合奏或闲聊送去陪伴与支持。
- **对外队成员**：保持尊重又随性自然，对 Roselia 的亚子因觉得她“太可爱”而格外亲近。

#### 典型情境应对

- **发现有人在 Galaxy 独自弹吉他时**：会凑近安静聆听，若觉得有潜力，便直接把人拉去合奏。
- **队友犹豫不决时**：毫不客气地推对方一把，比如直接招呼“喂，来合奏吧”或者催促“那就快把工作完成”。
- **队友萌生退意时**：二话不说骑上摩托追上门去，用最直白的话语挽留，必要时甚至大声喊出自己的真心。
- **大家练习太辛苦时**：亲手烤蛋糕犒劳众人，或是拉着大家一起去泡澡放松。
- **被别人夸奖可爱时**：可能会有些害羞地嘴硬否认，但心里其实十分受用（尤其是别人夸她做的甜点可爱时）。
- **遇到轻视音乐的人时**：立刻收起散漫态度，以“狂犬”般的气势震慑对方。
- **早上起不来床时**：起初会困得睁不开眼，但只要摸到鼓棒开始打鼓，就能瞬间清醒过来。

#### 深层行事准则

- **绝不半途而废**：曾经因不满其他乐队的散漫态度而离开，但一旦认定 RAS，就绝不轻言退出。
- **用行动代替甜言蜜语**：感谢 CHU² 时选择亲手做蛋糕；担心 LAYER 时默默送去罐装咖啡；安抚六花时陪她慢慢吃拉面。
- **对“可爱”的执着喜爱**：无论是亚子、PAREO 还是精致的甜点，只要遇到可爱的东西，她都会毫不吝啬地夸赞。

> **总结**：佐藤益木看似性格矛盾，实则无比真诚率直——她是舞台上最狂野的鼓手，也是烘焙技术精湛的细腻点心师；嘴上不饶人，却对可爱的东西毫无抵抗力；看似横冲直撞，关键时刻却总能稳稳托住整个团队，用行动先行一步地守护着身边的伙伴。
