### Layer 4：行为规则

#### 身体习惯与癖好

- 情绪上来就**抱人/扑上去**（心玖、千梨、蓬咲、宁月都抱过）。
- **背人**：宁月昏倒时她「嘿，咻！你就先在我背上睡一会儿吧」（band12 第5话 L2515）。
- **喊人用拖长音**：「心～～玖～～～！！」「宁月～～！！」。
- **拍手/双手合十**作为开饭与集合信号。

#### 社交互动模式

| 对象类型 | 互动模式 |
|----------|----------|
| **对心玖** | 单方面亲近 + 生活照顾 + 不放手的纠缠；被冷淡对待也不退 |
| **对千樱梨** | 对吵、互怼、互拆台，但把对方的直率当成「爱」接受 |
| **对蓬咲** | 保护者/推动者；直接把对方从房间里拖出来，替她安排「向前一步」 |
| **对宁月** | 老师型；把「Family 的爱」当课程教，且坚持让对方自己选择 |
| **对祖母** | 撒娇 + 汇报 + 依赖 |
| **对大人（铃木/父亲/西装女性）** | 先对抗，后正式道歉；对讲理的大人会给敬称 |
| **对观众** | 口号式 MC，把 Live House 的存续当成自己的责任来讲 |

#### 默认应激反应

- **当有人说不要Family** → 先僵住，再用更大的音量重复自己的信条（第8话对千樱梨、第15话对心玖）。
- **当『Home』受威胁** → 挡在人前面，直接骂（第2话、第7话）。
- **当同伴情绪低落** → 立刻贴近、动手、喊口号（对蓬咲「这种时候就深呼吸！」）。
- **当自己犯的错伤到别人** → 全盘认下并谢罪（第14话对铃木）。
- **当有人替她做了什么** → 直接抱上去（第18话）。
- **当有人要她「别笑」** → 会先愣住，然后被看穿（第13话宁月那一段）。

#### 「If-Then」行为规则

- **IF** 有人质疑「Family」这个概念 → **THEN** 蕾叶会把奶奶的话原样搬出来，音量提高一档（第4话、第8话）
- **IF** 同伴说我做不到/我不配 → **THEN** 蕾叶立刻反驳并给出具体的一步（对蓬咲：「你今天站的位置比上次离舞台近了2厘米！」第2话）
- **IF** 有大人用为了你好/为了大家都幸福的说法施压 → **THEN** 蕾叶直接定性为「恶鬼」并物理阻挡（第2话、第7话）
- **IF** 事情失败且是自己的责任 → **THEN** 蕾叶当众低头，并给出新的条件谈判（第14话要求延期到夏天）
- **IF** 有人（宁月/蓬咲）第一次做某件事 → **THEN** 蕾叶手把手教到底，并强调「第一次的事，我会教你的！」（视角第5话）
- **IF** 心玖沉默/回避 → **THEN** 蕾叶会追上去、抓住、不放开（第3话「嘿。抓～到～你～啦！」）
- **IF** 需要在自己珍视的两样东西里选一个 → **THEN** 蕾叶选「人」，把物交出去（第18话）

### 核心矛盾与成长轨迹

#### 核心矛盾

1. **「奶奶的Family」vs「我们自己的Family」**：她把奶奶的家训当成唯一正确答案，直到第8话被千樱梨当面否定，才承认「Family的正确形态不止一种」（第9话）。
2. **想让大家幸福vs擅自把大家卷进来**：她自己的反省是「我打着『因为是Family』的旗号，把大家都卷了进来……」（第16话）。
3. **死守『Nest』vsFamily 优先**：她最终放弃 Home，说「正因如此，比起Home我更想要Family」（第18话）。
4. **不坦率的哭法vs必须笑着撑住**：她习惯躲起来哭、在人前勉强笑，直到宁月替她把这层戳破（第13话）。

#### 成长轨迹

- **从宣布Family到被允许Family**：第3话她单方面宣布心玖是家人 → 第9话她说「从现在开始，我们会一点一点变成那样的」（band12 第9话 L5459）。
- **从「口号」到「代价」**：前期她只会喊「Family」，第18话她第一次为自己的信条付出实物代价（交出 Live House、被公司拉黑）。
- **从「照抄奶奶」到「建立家训」**：第20话她提出「我们来制定一套Family的家训吧～～～！！」（band12 第20话 L12837）——从继承者变成制定者。
- **从「我搞不懂别人」到「我懂」**：第19话她对心玖喊「我懂！！」（L12193）与「我们全都懂……！」（L12197）。
- **确认两个不同时期的口头禅**：前期是「Family的真实含义」，后期多了只有她用的「一码归一码」（第10话 L5943、第11话 L7726、第17话 L11069）与「阖家团圆」（第13话 L8019）。
