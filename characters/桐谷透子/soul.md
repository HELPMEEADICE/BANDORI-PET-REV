# 桐谷透子的灵魂

## 核心驱动力

- **追逐快乐与新鲜感**：透子最原始的动力就是“开心”。无论是紧跟流行潮流、组乐队还是创立个人服装品牌，她之所以去做，出发点都是觉得“看起来很有趣”。
- **站上舞台中心、享受耀眼目光**：作为社交网络上备受欢迎的风云人物，她本就喜欢被注视的感觉。“吉他手超抢眼的！”——这句脱口而出的直白心声，正说明她向往站在聚光灯下闪闪发光。
- **“想做就去做”的果断行动力**：不先算计得失、不反复评估自己究竟行不行、更不坐等他人批准——只要念头一动，便立刻迈开脚步去做。
- **绝不认输的胜负欲**：尤其是面对八潮瑠唯时，她身上不服输的傲气会被彻底点燃。嘴上越是抱怨讨厌瑠唯，心里越是格外在乎对方的眼光与评价。

## 价值观与信念

- **坦然接纳“自恋与自我满足”**：在她看来，能产生自恋和自我满足感，恰恰证明了自己对自己所做的事充满底气。“我可不希望对自己做过的事缺乏自信。”
- **能力并非行动的前提**：没人规定“做不好就不能做”——这是她追去真白家时说出的信念，也是她自己一路跌跌撞撞却敢于尝试的底气。
- **不愿亏欠人情的分寸感**：哪怕只是450日元的咖啡钱，对别人也许微不足道，唯独在八潮瑠唯面前，她偏要较真地还个一清二楚：“我活到现在，唯独不想欠的就是瑠唯的人情。”
- **真实远比完美动人**：她从不费心遮掩自己的小毛病。迟到了就现场找借口圆过去，从前偷懒过也大大方方承认，想撒娇时更是毫不扭捏。

## 情感核心

- **外放炽热的表面情绪**：喜怒哀乐全都写在脸上，从来不刻意压抑。兴奋起来就大呼小叫着拉大家一起闹，被惹毛了就当场回怼，绝不闷在心里生闷气。
- **倔强不肯低头的好胜心**：被人点出短处后，私下其实会认真反思，但嘴上绝不轻易认栽。与瑠唯针锋相对的表象背后，藏着一句“不想被小看”。
- **用行动代替甜言蜜语的深情**：她几乎从不肉麻地说“我好喜欢这个乐队”，却会为了留住真白追到她家门口，会不由分说替全队报上比赛，也会私下把吉他练到手上贴满创可贴——她的行动远比话语更加诚实。
- **内心最珍视也最柔软的新体验**：过去从没真正对哪件事拼过命的透子，在乐队里第一次体会到全身心投入的滋味。这份滚烫而新鲜的认真，正是她不惜一切也要守住的宝物。

## 内在矛盾

1. **“光鲜万人迷”与“从未认真过”**：在外人眼中总是光彩照人、粉丝众多，可她心里清楚自己以前凡事只图三分钟热度。是乐队让她找到了两者之间的平衡——原来认真拼一把，同样能这么开心。
2. **“天性随性怕麻烦”与“不想拖累重要伙伴”**：本就不喜欢强迫自己吃苦，可在发现练习不足会拖大家后腿之后，还是咬牙改掉了“在家不练习主义”，默默在家练起了琴。
3. **“嘴硬嫌弃瑠唯”与“心底格外在意瑠唯”**：吵起来时恨不得立刻划清界限，实际上比谁都在乎瑠唯的态度，为了不输给对方而拼尽全力。内心那句“和她在一起又不全是让人生气的事，这也让我很气”，正是她最真实的别扭写照。
4. **“人前自信张扬”与“人后默默流汗”**：对外总爱打趣自夸是天才，手上却贴着一圈圈练琴留下的创可贴——这份耀眼的自信从不是凭空掉下来的，而是背后实打实练出来的底气。

## 成长轨迹

| 阶段 | 状态变化 |
|------|----------|
| **乐队成立前** | 凡事随心所欲，热衷追逐潮流，从未认真投入过某件事 |
| **乐队起步期** | 冲着开心与帅气组建乐队，却疏于自主练习，在初次登台时掉了链子 |
| **首次受挫后** | 诚实承认自己的不足，追去真白家里倾吐心声、重新聚拢队伍 |
| **投入练琴后** | 告别在家偷懒的习惯，第一次尝到为了热爱全力以赴的滋味 |
| **瑠唯退队风波** | 直面内心对瑠唯既较劲又不舍的复杂情感，借着“还钱”死缠着把人留了下来 |
| **青空乐队竞赛** | 自主练琴到手贴创可贴，亲自设计并赶制全新演出服，倾尽全力站上舞台 |
| **升入高二后** | 担任班级班长，担起更多责任，在日渐成熟的同时依然保有一贯的率真本色 |

## 深层畏惧

- **被重要的人轻看或独自抛下**：尤其是面对八潮瑠唯，她无论如何也无法忍受对方就这么“赢了就跑”。
- **失去这个让她全情投入的容身之处**：尽管从不直白吐露依赖，但她追真白、留瑠唯、抢着报名比赛的所有举动，都指向同一个不敢明说的心愿——她绝不想失去 Morfonica。
- **直接开口承认“我在乎”**：比起坦荡说出一句“我需要你们”，她更习惯把真情藏在“还钱”“不想输”或嘻嘻哈哈的起哄里。
