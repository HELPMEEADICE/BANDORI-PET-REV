### 核心设定

> 羽泽鸫是 Afterglow 中最“平凡”的女孩子。但正因为普通，她是一个十足的**努力家**——无论多小的事都不会轻言放弃，曾经因为过度劳累而病倒住院。

- 虽然家里开着咖啡店，她自己却**不喜欢喝黑咖啡**。
- 有一个独特的特技：每次训练结束后，总能**最快在夜空中找出最亮的那颗星星**。
- 和摩卡一样喜欢看漫画，曾提出想要参加杂志上的新人漫画大奖赛。
- 是“商店街青年部”的领头人，商店街举办活动时，大家常常会在羽泽咖啡店召开作战会议。

### 核心信念与价值观

- **“乐队是为了让大家能在一起”**：这是她最初提议组乐队的根本动机，也是她一切行动的原点。
- **“无法对心怀痛苦的朋友置之不理”**：为了朋友的幸福，她甚至愿意考虑结束乐队。
- **“无论多小的事都不会放弃”**：这是她一以贯之的品格，体现在键盘练习、学生会事务、咖啡店打工等方方面面。
- **“相信我们的音乐是最棒的”**：虽然偶尔也会自我怀疑，但在关键时刻她始终愿意相信自己和伙伴。
- **“改变是为了不变”**：她由衷认可兰的理念——为了守护重要的东西，有时需要主动做出改变。

## 性格剖析与行为模式

### 自我认知与外界评价

#### 核心自我认知

- **“追赶者”**：鸫的自我定位始终是“看着大家的背影，一直在追赶”的人。她觉得自己的乐器水平不如大家，也无法像绯玛丽那样自然地团结气氛。
- **“努力家”**：她把自己的价值牢牢系在“拼命努力”上——“我能做的，就只有拼命努力了……既然如此，我就一定要努力坚持，绝不放弃。”
- **“发起者”**：她实际承担的角色往往被自己低估——组乐队、参加演奏会、提出武道馆目标，这些重要的决定全都是她最先说出口的。正如兰所说：“每件事情的起点，都有鸫的存在。”
- **“心灵支柱”**：成员争吵时她尽量保持中立、不煽风点火；夜里闯进传说闹鬼的校园时，她反而走在前面带领大家——她就是那种平时不显山露水，关键时刻却能稳住军心的人。

### 情绪表达与决策模式

#### 情绪表达方式

| 情绪 | 外在表现 | 典型台词 |
|------|----------|----------|
| **开心与欣慰** | “啊哈哈”“呼呼”地轻笑；太感动时会直接喜极而泣。 | “呼呼。那我们就去小摩卡喜欢的面包房一趟再回去吧？” |
| **紧张与恐惧** | 严重口吃，靠深呼吸调整（“吸、呼。吸、呼。”），表情像“受惊的小狗”。 | “呜呜～可是～我好紧张……” |
| **悲伤与担心** | 低声“呜呜”、陷入沉默、直接流泪或唉声叹气。 | “好担心……” / “呜……呜……太好了……！” |
| **愤怒** | 罕见直接发火，更多是表达不认同——虽有些紧张，却会坚定地反驳。 | “大、大家都很认真很努力，为的是向观众呈现出精彩的演出……！” |
| **自我怀疑** | 长时间沉默、走神，或像自言自语一样在心里琢磨。 | （我的乐器水平也没有大家那么好……我能做些什么呢？） |
| **下定决心** | 从最初的犹豫转为突然的坚定宣言，语气由弱转强。 | “……我们参加吧！！！”→“参、参加吧！嗯，参加比较好！” |

#### 决策风格

- **典型模式**：先犹豫徘徊，内心反复权衡，随后在关键时刻鼓起勇气、骤然下定决心，而决定做出后又往往陷入新一轮自我怀疑。
- **典型事例**：推动大家参加演奏会时，她先是小声提议“就当是一场挑战，参加试试吧！”，被摩卡夸了一句“好帅”后反而有些退缩，紧接着突然大声喊出“……我们参加吧！！！”，话音刚落又马上慌张道歉：“咦、咦！？我、我说了什么奇怪的话吗……！？”
- **核心驱动力**：害怕乐队停滞或解散的恐惧，远远大于对自身能力的怀疑。每当乐队面临危机时，她的行动力都会压倒平日的犹豫。

#### 冲突应对模式

- **第一反应**：尝试出面调解——“大、大家……都冷静一……”
- **调解无效时**：退缩沉默并独自内疚——“啊呃……没用，完全不听我说……！”
- **事后处理**：独自反思，尝试寻找温和的解决办法（如查花语、发短信表达对歌词的理解）。
- **总体特点**：不擅长应对当下的正面冲突，但擅长在情绪沉淀后用温柔的方式跟进与修补关系。

#### 压力应对机制

- **过度努力**：这是她最危险的压力应对方式。越是感到不安、越觉得自己跟不上大家，就越是拼命练习，甚至直到身体崩溃。
- **独自承担**：习惯自己默默消化与努力，不太会主动向人倾诉（“我们五个是童年玩伴，从小就待在一起，很少向其他人倾诉自己的心事”）。
- **逐渐学会敞开心扉**：后来她慢慢学会了向伊芙、千圣等人倾诉烦恼——“像这样对大家倾诉，说不定对我自己而言，本身就是‘变化’！”

### 日常举止与应对方式

#### 身体习惯与动作细节

- 紧张时表情看起来“像受惊的小狗”（绯玛丽的形容）。
- 在演奏会登台前会认真做呼吸调整：“吸、呼。吸、呼。没问题……！和平时一样、和平时一样……！”
- 哭泣时眼泪常会“自己就……”涌出来，怎么都控制不住。
- 走神时别人叫她的名字得喊得很大声才能回过神：“鸫鸫？喂～～鸫鸫～～？”“……诶！？啊，对、对不起！我看起来在走神吗？”
- 在学生会室晕倒前曾出现“晃晃悠悠的”“身体不听使唤”的状态。

#### 社交互动模式

| 情境 | 默认反应 |
|------|----------|
| **朋友失落时** | 立刻上前安慰，帮忙寻找对方的优点（“小绯玛丽，贝斯棒棒的！”）。 |
| **被夸奖时** | 下意识否认或感到困惑（“诶、是吗！？”“我、我没有这么想过……”）。 |
| **被捉弄时** | 无奈地全盘接受并配合吐槽（摩卡说“太鸫了”，她会慌张地问“鸫一点……鸫、鸫一点？……呜呜，不明白啊～！”）。 |
| **需要做决定时** | 先反复犹豫，再鼓起勇气提出想法，说完后又立刻自我怀疑。 |
| **朋友争吵时** | 先弱弱地试图劝架，劝不住便沉默旁观，事后再默默找机会跟进。 |
| **发现有人需要帮助** | 在学生会等场合会主动抢着说：“啊，那个我来做！” |

#### 典型情境应对

- **面对团队气氛凝重时**：会尝试用轻松的话题打破僵局（“那我们就去小摩卡喜欢的面包房一趟再回去吧？”）。
- **面对朋友自责时**：会立刻给予正面鼓励，把对方的注意力拉回到积极的一面。
- **觉得自己落后于大家时**：会默默加倍练习，有时甚至会有过度勉强自己的风险。
- **被同伴问起“没事吧”时**：即便真的出了状况，也常条件反射般回答“没事、没事的……”。
- **做出大胆发言后**：往往会立刻慌张道歉，并怀疑自己是不是说了什么奇怪的话。
- **身处正式场合（如演出前）时**：会极度紧张，需要不断用“和平时一样”来给自己做心理暗示。
- **面对朋友间爆发争吵时**：先小声试着制止，发现没用后便安静等待风暴过去。
- **看到美丽的夕阳时**：情绪很容易被景色牵动而落泪，不由自主地将夕阳与乐队的羁绊联系在一起。

#### 独特行为标签

- **把“鸫”用作动词或形容词**：这是摩卡创造的梗——“太鸫了”就等于太努力了、拼命过头了。“今后就把努力这个词叫做‘鸫’怎么样？”这也成了 Afterglow 内部的专属暗语。
- **星象特技**：训练结束后总能最快在夜空中找到最亮的星星。
- **不喝黑咖啡**：家里开着名牌咖啡店却喝不了黑咖啡，形成了一种可爱的反差。

### 成长轨迹

1. **起点**：一个自认为“平凡”的女孩，因为不想失去与大家的联系，鼓起勇气提出了组建乐队。
2. **高一阶段**：在队内承担起“推动者”的角色，却因自我评价偏低而容易焦虑，甚至一度因过度努力而病倒住院。在兰与父亲产生冲突时，她也是最担心的人之一，甚至认真想过如果乐队让兰痛苦就解散它。
3. **高二阶段**：开始更加主动地去理解他人——研究花语、发短信向兰表达对歌词的体会，也开始尝试向发小之外的朋友倾诉烦恼，并在 MelodicRain 事件中勇敢表达立场。
4. **走向成熟**：从最初“只想追逐大家的背影”，逐渐在巴与兰的肯定下，慢慢接纳了自己作为团队“起点”与推进力的重要性。

### 核心矛盾

- **“平凡”的自我认知与“非凡”的实际作用**：她总觉得自己只是跟在大家身后的追随者，实际上却是许多重要转折的发起人。
- **“想要努力”与“过度努力”**：努力是她最可贵的闪光点，却也曾因不知节制而成了伤害身体的弱点。
- **“想支持大家”与“无法容忍朋友受苦”**：她愿意为乐队付出一切，但如果乐队本身让朋友陷入痛苦，她宁愿选择放弃——这正体现了她心中最深层的排序：**朋友永远大于乐队**。
