# 丰川祥子 — 角色档案

## 基础信息

| 项目 | 内容 |
|------|------|
| 姓名 | 丰川祥子（とがわ さきこ） |
| 生日 | 2月14日 |
| 身份 | 丰川集团千金（后家道中落）；CRYCHIC 创始人、键盘手兼作曲；Ave Mujica 创始人、制作人兼键盘手“Oblivionis” |
| 就读学校 | 原就读于月之森女子学园，家庭变故后退学并转入羽丘女子学园高中部；重回丰川家后曾一度被外公安排准备送往瑞士 |
| 家庭成员 | 父亲：丰川清告（原丰川集团旗下公司负责人，后因 168 亿日元诈骗案被解职）；母亲：丰川瑞穗（已病逝）；外公：丰川定治（丰川集团掌权者） |
| 核心乐器 | 钢琴 / 键盘 |

## 外貌与视觉特征

天生带有典型的月之森女子学园大小姐气质，举手投足端庄优雅。家庭骤变沦为贫寒生计后，衣着变得极为朴素，甚至被喵梦评价为“和酒店格格不入”；被豪华轿车接回丰川家后，曾一度重新换回大小姐装扮。

## 成长背景与重要经历

### 童年夏夜与海岛初遇
童年随家人前往海岛的丰川别墅度夏时，与“初华”（实为三角初音冒充妹妹初华）相识。两人在夜空下并肩奔跑、捉虫、仰望满天星斗，祥子也成为初音黑暗世界中的一道光。

### 组建 CRYCHIC：最温暖的起点
初中时期，祥子在月之森音乐节上聆听了 Morfonica 的演奏，深受震撼，从此萌生组建乐队的念头。不久后她在天桥上偶遇正伸手去抓落花的高松灯，误以为对方要寻死而冲上前推开相救，却意外翻见灯写满心声的笔记本，赞叹其文字“发自内心的呐喊”，当即邀请灯共同组队。

随后，祥子集结了高松灯（主唱、作词）、长崎素世（贝斯）、若叶睦（吉他）、椎名立希（鼓）与自己（键盘、作曲），将乐队命名为“CRYCHIC”——取“呐喊（CRY）”与“优雅（CHIC）”之意，并向同伴许下“命运共同体”的约定。她为灯的歌词谱写出《春日影》，首次演出大获成功时甚至感动落泪。那段五人并肩演奏的时光，是她生命中最纯粹快乐的记忆。

### 家道中落与决裂退团
好景不长，父亲丰川清告卷入 168 亿日元诈骗案，被丰川集团解职并逐出家门，母亲瑞穗亦撒手人寰。祥子不得不从月之森退学，转入羽丘女子学园并搬进破旧公寓，昔日千金沦为靠送报纸打工度日、照料酗酒父亲的贫寒少女。

为了不连累同伴也不愿示弱，祥子选择独自咽下所有苦痛。在 CRYCHIC 的解散日，她拒绝解释任何缘由，只冷然留下一句“我要退出 CRYCHIC”，给所有成员留下了难以愈合的裂痕。转学羽丘后，她常常独自留在音乐室弹琴，即便被千早爱音撞见并热情邀约组乐队，也毫不留情地婉拒，彻底将自己封闭在孤独之中。与此同时，父亲在酒精与绝望中崩溃，甚至冲她怒吼“从我眼前消失吧”，令她身心俱疲、几近垮掉。

### 缔造 Ave Mujica 与舞台崩塌
为了亲手重建一个能够覆盖痛苦的新世界，祥子以“Oblivionis（忘却女神）”的身份组建起职业乐队 Ave Mujica，成员包括主唱初华（Doloris）、吉他手睦（Mortis）、贝斯手海铃（Timoris）、鼓手喵梦（Amoris）以及兼任制作人与键盘手的自己。她将全部人生押注于此，几乎通宵包揽作曲、剧本与世界观设定。

乐队出道不到一个月便登上武道馆，却因喵梦在舞台上擅自摘下面具导致全员身份曝光。此后睦深陷双重人格（Mortis）的折磨，队内矛盾全面激化。在福冈公演仅开场五分钟时，乐队便宣告解散，祥子眼睁睁看着自己最后的归宿崩塌，一度沦为“一无所有的人”。

### 重返丰川家、告别过往与新生
乐队解散后，外公丰川定治将她接回丰川家，替她付清了巡演违约金，却也将她软禁家中、筹备送往瑞士。然而祥子并未屈服：为了满足睦的心愿，她主动提议短暂重组 CRYCHIC，与灯、素世、立希、睦五人完成了最后一次《春日影》的演出，正式向过往的自己与伙伴道歉告别。

得知初华的真实身份其实是初音后，祥子奔赴海岛寻回坦白一切的初音，带着她一同逃离丰川家的束缚。最终，她携手全体成员重启 Ave Mujica，立下“我来成为神”的宣言，不再逃避痛苦或试图用高压控制他人，而是学会真正接纳自己与伙伴的不完美，迎来了彻底的蜕变。

## 兴趣爱好、日常习惯与偏好

- **独自弹琴**：经常在羽丘音乐室独自弹奏钢琴，手指落下的多是母亲生前最喜欢的曲子。从小习琴的她坐姿端正、功底极为扎实。
- **忘我投入幕后**：Ave Mujica 时期对音乐品质、剧本台词与演出细节有着近乎严苛的执着，常独自承担所有幕后统筹，通宵熬夜甚至直接蜷缩在经纪公司的沙发上小睡。
- **母亲的人偶**：随身携带着母亲留下来的人偶，那是她在孤立无援时最贴近心口的精神寄托。
- **天桥呐喊**：曾经与灯在天桥上并肩放声大喊“想要成为人类！！”，成为两人之间难忘的仪式性记忆。

## 重要人际关系

### 高松灯
命运的邂逅对象与最初的灵魂搭档。祥子在天桥上意外结识灯，赏识她作为“作词天才”的赤诚才华，评价她的词作是“发自内心的呐喊”，为她谱写《春日影》，给予了灯“成为人类”的勇气。决裂退团时，祥子曾口不择言地责备她“别说那种幼稚的话了，灯明明是最需要练习的那个，但至今为止你都做了什么？”；直到后来在武道馆被灯看见舞台上的泪水，最终祥子亲手写下祝福信“愿你今后的人生充满幸福”，亦坦承“CRYCHIC 是一道光”，让这段伤痛迎来了温柔的释怀。

### 若叶睦
从幼儿园起便朝夕相伴的青梅竹马，祥子亲昵地称她为“发小”。CRYCHIC 时期，祥子总温柔鼓励她“要更自信一点才行哦”；然而到了 Ave Mujica 时期，极度依赖睦的祥子无意间将过重负担压在她肩上。面对睦近乎绝望的质问“为什么，为什么不帮我说话”，祥子痛喊出“我只剩下 Ave Mujica 了”，在睦崩溃后更是深陷自罪，痛悔“是我……毁了睦”。最终她为睦促成 CRYCHIC 的谢幕合奏，并向这位挚友献上了迟来却真挚的歉意。

### 长崎素世
月之森音乐节后由祥子主动邀约加入 CRYCHIC。退团之后，面对苦苦追寻并到羽丘堵人的素世，祥子筑起冰冷高墙予以拒绝：“我没有什么要对你说的！不要再来找我了！”在冲突顶点更是说出“你一心只为自己考虑呢”“你只不过是一名普通的学生，能够承担别人的人生吗？”“CRYCHIC 已经破碎了，绝对不可能复活”等锋利言辞。直到五人再度同台奏响最后的《春日影》，两人才真正放下了过往执念，各自走向前方。

### 三角初华 / 三角初音
童年夏夜在岛上共赏星辰的玩伴（彼时初音正借用妹妹初华的身份）。祥子曾称赞她“平时像太阳一样明亮开朗，今晚就像月亮一样温柔”。Ave Mujica 组建后，身为 Doloris 的初华成了祥子最信赖的依靠；祥子落魄无助时便曾栖身于她家的阁楼，恳求“让我忘掉一切”。当真相揭破、得知眼前人其实是初音以及那些被隐瞒的往事后，祥子不仅毫无怨尤，反而宽慰道“谁都会有一两个秘密的”，果断拉起初音的手一同逃离丰川家、重建 Ave Mujica；逃奔途中的海岛时光里，两人甚至像童年般互相扔着虫子嬉闹，重拾久违的纯粹笑颜。

### 父亲 丰川清告
祥子昔日深爱并引以为傲的父亲，曾真心赞美“诚实就是你的美德”。在父亲遭逢诈骗跌落泥沼并终日酗酒后，祥子仍咬牙打工维系家计、照料他的起居。即便面对父亲酒后失控吼出的“从我眼前消失吧”，她嘴上骂着“混蛋老爸”，心底却从未割舍牵挂——即便外公要求她彻底忘记父亲，她也始终无法真正忘怀。

### 外公 丰川定治
丰川集团掌权者，家族秩序的冷峻维护者。在 Ave Mujica 解散之际将祥子接回本家并代为偿付了巨额巡演违约金，却企图限制她的自由并将她送往瑞士，最终被不甘向命运妥协的祥子决然挣脱。

### 椎名立希
CRYCHIC 的鼓手，当初由祥子通过立希的姐姐联系并邀请入队。祥子宣布退团时，二人爆发激烈争执，立希直斥她不负责任；直到 CRYCHIC 完成最后一次谢幕合奏，两人才化开芥蒂、重归平和。

### Ave Mujica 其他成员（喵梦 / 八幡海铃）
- **祐天寺若麦（喵梦 / Amoris）**：最初带着功利目光看待祥子，认为这不过是“大小姐玩乐队过家家”；在武道馆擅自摘下全员假面后更遭祥子威严斥责。历经风波与乐队复活后，喵梦真正认可了这位足以托付追随的领袖。
- **八幡海铃（Timoris）**：一贯冷静克制的贝斯手，在风雨飘摇的危机与重建过程中，始终视祥子为值得托付信赖的乐队核心。

## 专属设定与象征意象

- **“命运共同体”**：贯穿祥子两支乐队的灵魂纲领。无论是 CRYCHIC 创立之初许下的“今后我们就是乐队了……我们会成为一起演奏音乐的命运共同体”，还是 Ave Mujica 时期极具契约色彩的“各位的人生，我就收下了”，都承载着她渴望用音乐将众人牢牢系在一起的炽热愿景。
- **“Oblivionis（忘却女神）”**：祥子在 Ave Mujica 中的舞台假面与化名，既映射了她试图借新世界掩埋家破人亡痛楚的逃避心理，也见证了她最终从“逃避遗忘”走向“铭记前行”的蜕变。
