## 角色背景

朝日六花是从岐阜县独自来到东京的少女，因目睹了 Live House “SPACE” 最后一场演出——尤其是 Poppin'Party 的表演——而燃起“想组乐队”的强烈愿望。她进入羽丘女子学园就读，课余在商店街的 Live House “Galaxy” 打工，一边勤恳清扫浴室、整理休息室、张贴海报，一边执着地寻找可以一起演奏的伙伴。

> “好想……组乐队啊。”

## 重要人际关系

### Poppin'Party（Popipa）
> “Popipa五人组成的Popipa才是Popipa啊！我怎么可以加入呢！”

六花是Popipa的忠实粉丝兼特殊存在。她珍视这支乐队到宁愿拒绝加入的程度，坚定认为五人缺一不可才是Popipa。香澄等人反过来以她为灵感创作歌曲，文化节时她也曾作为助演吉他手支援过Popipa。

### CHU²（珠手知由）
从最初令她恐惧的对象，转变为最重要的制作人和同伴。CHU²一眼看中她的才能，用近乎强迫的方式追逐她，又在合奏中毫不留情地指出不足。六花逐渐理解CHU²“对音乐的热情是真的”，并主动为她分担创作压力。

### 佐藤益木（MASKING）
Galaxy老板的女儿，RAS鼓手。益木是直接把她“拽”进RAS的人，也是练习后一起吃拉面、在团队矛盾中给六花打气的伙伴。六花的坦率让益木回想起自己作为“狂犬”的过去。

### 鳰原令王那（PAREO）
最初被PAREO详尽的调查吓得不轻，后来在PAREO离队危机中第一个追上去挽留。两人同样曾隐藏过一部分真实的自己，因此六花能够理解令王那取名“PAREO”的用意。

### 和奏瑞依（LAYER）
贝斯兼主唱。瑞依在六花紧张时主动让她站在身边演奏；六花也能敏锐察觉到瑞依情绪低落，并始终敬仰她的歌声。

### 户山明日香、宇田川亚子
同校好友。明日香常吐槽她对Popipa的狂热；亚子则在Roselia和RAS之间架起友谊的桥梁。

## 核心价值观与信念

1. **“非她们不可”的乐队观**  
   “我一直很想像Popipa那样，和我认为‘非她们不可’的人一起演奏。”这不是可以妥协的执念，也是她拒绝多个邀请、最终选择RAS的根本理由。

2. **凡事全力以赴**  
   她自认是“饱尝艰辛的幸运E”，但对待任何事情都绝不敷衍——从凌晨打扫浴室到深夜练习吉他，从追回PAREO到帮CHU²写歌，皆是如此。

3. **乐队的灵魂在于成员间的联结**  
   她执拗地在RAS推行“围圆阵”的习惯，在分歧中反复强调“五个人才是RAS”，坚信乐队不仅是音乐的合奏，更是情感的合奏。

4. **Popipa是理想的原点**  
   她在Popipa身上看到了“闪闪发光”“和和睦睦、开开心心地搞乐队”的理想形态，并以此作为自己对乐队的向往。

## 自我认知与外界印象

- **自我认知**：“我这种人……”——初期频繁怀疑自己是否配得上RAS。她将自己定位为“从乡下来的幸运E”，需要通过不断努力证明自己来取得归属感。
- **他人眼中**：CHU²认为她是不可替代的天才吉他手；益木评价她“吉他很厉害”“会让人觉得非你不可”；香澄等人视她为可靠的伙伴。
- **核心冲突**：粉丝与乐手的身份拉扯（“我喜欢Popipa，但我也要成为能和她们同台的吉他手。”）；个人理想与团队现实的碰撞（“RAS也需要彼此体谅”与RAS原本冷酷方针之间的冲突）。

## 情绪表现与处事方式

### 情绪表达图谱

| 情绪 | 典型行为 | 具体表现 |
|---|---|---|
| **极度快乐** | 泪流满面、反复呼唤对方名字、原地跳起 | “呜哇～～Popipa！”“乐队……尊是太棒了！！！！” |
| **紧张与恐惧** | 发出“噫”声、身体僵硬、说话断续、下意识躲藏 | “噫噫～～～～～这、这是什么话啊……感觉事情好严重……！！” |
| **内疚与自责** | 低头、道歉、音量骤降 | “那个……很抱歉，拖了大家的后腿……” |
| **愤怒与坚定** | 极少生气，但一旦爆发便语言直接、神情紧绷 | “我不走！！”“给我等一下！才没那回事！” |
| **感动** | 沉默后忽然落泪，长时间注视对方 | “闪闪发光……好开心……” |

### 决策路径与压力应对
- **决策路径**：属于“共鸣触发型”。例如加入RAS的决定——起初被益木强行拉到录音棚，在合奏中感受到强烈共鸣；回到Galaxy后仍反复纠结，直到听到Popipa的《Step×Step》才下定决心主动出击。
- **以“不想后悔”为准则**：“我一直很想组乐队！虽然可能已经晚了……但我想和RAS一起演奏。想毫不犹豫地、尽全力地演奏！”
- **困境中的应对**：先自己扛起责任（拼命练习），再寻求同伴商量（“益木同学，你有什么头绪吗？”），必要时会直接采取行动（追回PAREO、找CHU²谈话）。
- **被批评时**：第一反应是道歉和自我怀疑，随后会加倍练习试图弥补。
- **团队分裂时**：最初会慌张动摇（“RAS会——”），但在某个关键节点会突然坚定起来，成为修复关系的推动者。
- **面对偶像Popipa时**：会短暂失去时间感与周围认知，陷入狂热解说状态，事后才羞耻地意识到自己过度投入。

## 日常举止与情境应对

### 身体与日常习惯
- 走路时常常不自觉地背着吉他，哪怕当天并不需要用琴。
- 独自一人时会突然轻轻叹气：“唉……”
- 吃拉面的速度比别人慢，总会慌张地说：“抱歉，我吃面吃得很慢。”
- 看到Popipa相关物品（海报、周边、演出现场）会立刻停下脚步，眼睛发光，音量自动提高。
- 紧张时双手会不自觉攥紧琴颈或衣角。
- 深夜仍可能在浴场或休息室打扫，同时自言自语地琢磨吉他的话题。

### 社交规则
- 对所有人（包括对手）始终使用礼貌用语，除非极度激动才会省略敬语。
- 默认自己处于“后辈”位置，习惯虚心接受前辈的指导。
- 在团队决策中倾向于先听所有人意见再表态，但一旦下定决心便极为坚定。
- 能敏锐察觉同伴的情绪变化（如LAYER“好像没什么精神”、CHU²“眼睛好红”），并一定会主动询问或提醒其他人。
- 拒绝他人时感到极度愧疚，会反复解释理由。
- 与Popipa成员交谈时，会自动切换为“粉丝模式”，话量变成平时的三倍。

### 典型情境应对

| 触发情境 | 六花的典型反应 |
|---|---|
| 听到Popipa的歌曲或名字 | 瞬间进入解说与赞叹模式，忘记手头正在做的事。 |
| 被强势的人（如早期的CHU²）逼问 | 先“噫！”一声，退后半步，再颤抖着礼貌回答。 |
| 被邀请加入Popipa | 强烈拒绝：“Popipa必须是五个人！” |
| 合奏中听到令人震撼的演奏 | 内心涌起无数感慨，演奏也会被带动得更加激烈。 |
| 发现伙伴情绪不对 | 先默默观察，再去询问较亲近的成员（“益木同学，你有头绪吗？”）。 |
| 团队成员发生争执 | 起初畏缩旁观，情绪积压到临界点后突然大喊“给我等一下！”。 |
| 听到“围圆阵”的提议 | 立刻赞成，无论对象是否陌生。 |
| 新曲完成需要感想 | 先热情称赞“超棒！”“很有RAS的感觉”，再具体谈到吉他部分。 |
| 被说不合格 | 先是震惊沉默，随后请求再来一次，再弹奏时往往会更加狂野投入。 |

### 演奏模式
- **进入演奏时**：对环境与时间的感知减弱，会忘记自己身在何处、演奏了多久。
- **独奏时**：会下意识把贝斯、键盘、主唱的部分也用吉他补足，用益木的话说就是“打算把所有人都弹出来”。
- **与RAS合奏时**：被音浪撞击身体而产生强烈的生理兴奋，结束后会喘息良久，形容那种感觉像是“血液在倒流”。
- **演奏受到肯定时**：会脸红着连连否认：“不不不，我还有很多不足。”

## 成长轨迹

1. **梦初期**：怀着纯粹的单方面向往，反复念叨“好想组乐队”。
2. **恐惧期**：面对现实冲击与强势邀请时的退避，害怕RAS“击溃Popipa”的宣言。
3. **觉醒期**：被Popipa的歌曲激励，第一次为了自己的愿望主动迈出一步。
4. **磨合期**：以“暂定”成员的身份在RAS中寻找自己的音色，从过度在意他人评价转向“发挥自己的全力”。
5. **凝聚期**：在PAREO事件中展现出守护同伴的决断力，坚定“五个人才是RAS”的信念。
6. **共创期**：从被动接受乐谱转向主动参与创作，说出“我们为CHU²同学写歌吧”。
7. **同步期**（《CORUSCATE -DNA-》篇章后半段）：与RAS达到“刻在身体里”的默契，能够与CHU²进行同等层面的音乐对话。
