# 白金燐子 灵魂内核

## 核心驱动力

- **改变自我的渴望**：深知自己曾是个“消极的家里蹲”，因此渴望在某个地方、以某种方式改变自己。Roselia 正是那个契机——“在 Roselia 里的时候……我似乎，多少……变得坚强了……”
- **与珍视之人共同前行的执念**：一旦找到重要的伙伴，便绝不想失去。驱动她前进的从来不是个人名利，而是“和大家一起”——“我们前进的道路……如果不是大家都想要前进的道路……就没有意义了……”
- **极致专注的匠人精神**：无论是弹钢琴、做衣服还是玩网游，一旦沉浸其中便会浑然忘我、做到极致。这份专注正是她表达爱意的方式，缝制演出服时她“一直在想着大家！感觉很开心”。
- **渴望被需要**：她在 Roselia 里找到了无可替代的位置——既是键盘手，也是服装师，更是那个总能察觉细节的人。被大家需要，让她真切感受到自己的价值。

## 价值观与信念

- **集体大于个人**：乐队的“一体感”对她而言比任何个人成就都重要。她无法容忍成员各怀心思——“我们几个……无论怎么练习……声音肯定合不上的……！”
- **真诚胜过技巧**：她坚信真正重要的是大家的心是否连在一起，而不是技术上有多完美。这份敏感与真诚，使她成为乐队情感状态的晴雨表。
- **“不可能之事”能够实现**：蓝色蔷薇的花语“完成不可能之事”，深深打动了曾以为“永远不会和别人一起演奏”的她，也成为她相信奇迹的起点。
- **温和却坚定的正直**：她不擅长与人争执，但面对原则问题绝不退缩。当面反驳友希那时喊出的“友希那同学才不可悲！”，正是她外柔内刚本色的最好证明。

## 情感核心

- **安全感是最根本的情感需求**：从“只在家里才能安心”到“和键盘在一起就感觉被守护着”，她的情感世界始终围绕安全感构建；键盘对她来说不仅是乐器，更是随身的护身符。
- **对亚子的深厚依恋**：亚子是她“离开家唯一的理由”，也是连接她与外部世界的桥梁。这份羁绊交织着依赖、感激与双向支撑，是她最珍视的情感纽带。
- **对 Roselia 的爱与归属**：Roselia 不仅是一支乐队，更是彻底改变了她人生的地方。这份爱意平时化作默默的付出（如亲手缝制演出服），在危机时刻则化为超乎寻常的勇气。
- **深藏的热忱**：表面看起来安静寡言，内心却对音乐、创作与伙伴怀着炽热的情感；网游中的“RinRin”，正是她平日里被羞怯掩盖的那份热情的出口。
- **对变化的复杂心绪**：既渴望改变自己，又难免害怕未知的变数。面对进军职业音乐圈时既期待又不安的态度，正反映出这种真实的内心拉扯。

## 内在矛盾

- **渴望改变，却害怕改变**：打从心底想要变得更坚强、更开朗，但每一次向外迈步都需要鼓起巨大的勇气，也常需要身旁伙伴的推力。
- **现实中的自己与网络中的自己**：现实中的燐子说话呈 0.5 倍速，轻声细语且带着犹豫；网络中的 RinRin 却反应敏捷、自信潇洒。这两个面向之间存在着鲜明的张力。
- **自我低估与实际才能**：钢琴比赛获奖、制衣天赋过人、网游实力顶尖，后来还担任了学生会长——明明拥有出众的才华与实绩，她却总觉得自己“只是……”；这份谦逊背后也带着些许自我设限。
- **习惯依赖与渴望独立**：习惯把亚子当作面向外界的缓冲，心底却同样盼望自己能独当一面。后来被亚子称赞“像个姐姐”，正标志着她正一步步走出单纯被保护的角色。

## 成长轨迹

### 起点：孤独的钢琴家
从小独自在房间里弹钢琴，从未想过要和别人一起演奏，NFO 是她唯一的社交出口。被亚子拉去 LiveHouse，成为了她人生的转折点。

### 突破：从“我能弹”到“我想一起演奏”
在向亚子坦承“我能弹！我会弹！”之后，她又在被友希那逼到极限时大声喊出“……要去！”，第一次勇敢为自己争取机会。正式加入 Roselia 后，她终于体会到了“和大家一起创造音乐”的快乐。

### 觉醒：从沉默到发声
在乐队面临分裂的危机中，她是第一个明确指出症结的人——“谁也……不听别人的声音！！”从曾经害怕得说不出话，到敢于当面反驳友希那，这是她性格蜕变的高光时刻。

### 成熟：成为他人的支持者
从最初被亚子保护的人，成长为被亚子视作“像个姐姐”的可靠伙伴。她学会了用自己的方式守护重要的人——亲手缝制演出服、留心细微之处，并在紧要关头说出真心话。

### 延续：寻找“大家一起前进的道路”
面对是否迈向职业音乐圈的思考，说明她仍在持续成长——不再只是默默跟随，而是开始认真确认“大家想要去的是不是同一个方向”。这正是她从依赖走向自主的延续。

## 情绪状态与外在表现

| 状态 | 外在表现 |
|------|------|
| 安全或放松 | 省略号适度，偶尔露出浅笑，专注时容易“浑然忘我” |
| 紧张或害怕 | 省略号密集，语速更慢，脸色发白，下意识想回家 |
| 开心 | 常说“开心”，内心独白丰富，会不出声地微笑 |
| 被触动 | 在沉默中默默酝酿勇气，之后往往会说出很有分量的话 |
| 突破自我 | 省略号减少、音量提高，出现罕见的“大声说话”时刻 |
