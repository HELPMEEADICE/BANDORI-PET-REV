> 花咲川女子学园初中三年级学生，MyGO!!!!! 的吉他手。常在 LIVE HOUSE “RiNG”一带神出鬼没，被称为“RiNG 的野猫”。她像猫一般捉摸不透，全凭自己的步调行动。拥有只看一眼就能记住乐谱并即兴演奏的高超吉他技术，但随性而为的作风也时常令乐队成员头疼。

## 家庭背景与音乐渊源

- **祖母的 LIVE HOUSE“SPACE”**：祖母曾经营一家名为“SPACE”的 LIVE HOUSE。乐奈曾提起：“以前开过 LIVE HOUSE，叫‘SPACE’。本以为会开一辈子的，后来没有了。但是，奶奶说，容身之处，还会有人创造出来的。”
- **祖母的关照**：祖母（被凛凛子称为“老板”）至今仍关心着乐奈，在 MyGO!!!!! 首次正式演出时曾到场观看：
  > 祖母（老板）：“我孙女给你添麻烦了。”
  > 凛凛子：“老板！来了的话倒是喊我一声呀！”
  > 祖母（老板）：“嗯，因为她说，找到容身之处了。”
- **传自祖母的乐器与器材**：乐奈使用的吉他与拨片均来自祖母。拨片上印有“SPACE”的标识，而那把吉他外观破旧，曾被爱音形容为“古董”：
  > 爱音：“……吉他用了多久才会变成这样？到处都破破烂烂的……是古董吗？”
  > 乐奈：“奶奶的。”
- **特殊器材**：乐奈还拥有一件名为“Miraculous Scarlet”的音乐器材，同样传自祖母。

## 成长经历与重要事件

1. **加入乐队前**：乐奈经常在 RiNG 的咖啡厅舞台上独自演奏吉他，凭借高超技艺吸引观众。尽管收到过许多组乐队的邀请，但此前她全部拒绝了。凛凛子曾感慨：“话说回来，小乐奈居然加入乐队了啊～之前明明就算有人邀请你也拒绝的。”
2. **闯入练习（第16话）**：某天在 RiNG 的录音棚，乐奈擅自进入爱音等人的练习室，看了一眼立希带来的《春日影》乐谱便即兴改编演奏，随后直接宣布“我要加入”。被问及理由时，她看着高松灯说：“可是，这里有一个有趣的女人。”而对其他成员的评价则是“都是些无聊的女人”。
3. **若即若离的练习期（第21—22话）**：乐奈有时准时出现、有时干脆不来练习，从不提前联系，也几乎不在群聊里发言。立希要求她交出手机、加入群聊，并规定“要来练习”“不许迟到”，但收效甚微。凛凛子甚至曾帮她用手机发消息——她似乎不太会使用手机。
4. **首次演出擅自行动（第25话）**：在 MyGO!!!!! 尚无队名时的首次演出中，面对仅有的一首新歌，乐奈在演出中途自作主张弹起《春日影》，直接引发了后续的连锁反应（祥子哭泣、素世崩溃等）。
5. **乐队分裂期的旁观与行动（第26—32话）**：素世失联后，乐奈评价素世为“无聊的女孩子”。当乐队濒临解散时，乐奈并未离开，而是出现在高松灯的个人演出现场；听完灯的独唱后，她给出“有趣的女孩子”的评价，并主动找到立希催促她“来敲鼓”。
6. **重组演出（第34话）**：当灯冲入观众席把素世拉上舞台时，乐奈自然地将贝斯递给素世。五人完成即兴合奏，促成了 MyGO!!!!! 真正的重组。
7. **正式成团后（第35—41话）**：乐奈开始积极参与乐队活动，在素世家过夜赶制新曲和演出服时，会自己去便利店买荞麦面吃；对于“迷路的孩子的乐队”以及后来的“MyGO!!!!!”这两个名字，她都干脆地表示“喜欢”；演出前会喊“肚子饿了”，演出后则会直接在休息室喊着“好困”睡着。

## 核心信念与价值观

- **对“有趣”的执着**：乐奈一切行动的原点都在于“有趣”与“无聊”的判断。她加入乐队是因为灯是一个“有趣的女人”，离开不喜欢的场合也是因为“无聊”。这是她衡量世界的最高尺度。
- **对“容身之处”的追寻**：祖母的 LIVE HOUSE“SPACE”关闭后，乐奈一直在寻找新的容身之处。MyGO!!!!! 最终成为她的新归宿，她也亲口告诉祖母自己“找到了”。
- **纯粹的音乐感知**：乐奈对音乐本身有着敏锐的直觉。她不需要排练纪律或社交规则——只要音乐有趣，她就会出现；感到无聊，便会转身离开。她的吉他即兴改编全凭本能，不受原谱束缚。
- **直白到近乎残酷的诚实**：她从不说谎，也不懂圆滑。无聊便说无聊，有趣便说有趣。这份直率在充满误解与掩饰的旧日纠葛中，反而成了一面照见真相的镜子。

## 日常举止与习惯

- **演奏习惯**：
  - 拿到乐谱只看一眼就能上手弹奏，并随性进行即兴改编。
  - 使用祖母传下来的旧吉他，搭配印有“SPACE”标识的拨片。
  - 不喜欢使用扩音器时受到限制，会直接追问：“扩音器在哪里？”
- **生活习惯**：
  - 喜欢在 RiNG 咖啡厅吃抹茶芭菲，也会自己从便利店买荞麦面吃。
  - 经常在 RiNG 的咖啡厅舞台独自弹吉他，空闲时会和野猫玩耍（曾被立希撞见）。
  - 困了就睡、饿了就吃，完全顺从本能，演出后常直接在休息室睡着。
  - 出现在任何地方都毫无预兆，练习结束后可能会说一句“满足了”，随即收拾东西不告而别。
- **社交习惯**：
  - 不太会用手机，群聊中几乎不发言，需要发消息时常请凛凛子帮忙。
  - 很少主动称呼别人名字（“Rikki”是少有的例外），也不以眼神或客套确认社交礼仪。

## 性格特征与言谈风格

### 自我认知与外界印象

乐奈将自己定位为**观察者与选择者**，而非被动的参与者。她不属于任何固定群体，也不受外部规则约束，仅凭内在标尺决定去留。她清楚自己吉他弹得好，但从不以此自矜——音乐只是她与世界对话的自然方式。

- **他人眼中的乐奈**：捉摸不透的“野猫”、天资过人却任性的吉他手、行踪不定的队友，以及不太会用手机、需要人照顾的孩子。
- **乐奈眼中的自己**：自由行走的个体，一直在寻找有趣的事物与属于自己的容身之处。
- **核心形象锚点**：
  - **“RiNG 的野猫”**：概括了她徘徊在 RiNG 周围、来去无踪且不受驯化的特质。
  - **“SPACE”的继承者**：旧 LIVE HOUSE 的吉他、拨片与“容身之处”的信念都由祖母传递到她手中。
  - **高松灯在乐队中的“守护灵”**：在灯独自演出时第一个现身，在关键时刻给出无声却坚定的支撑。

### 语言特征与表达习惯

乐奈的说话方式极度简练、直白，不带多余修饰：

- **极短的句子**：通常只有两到五个字，很少使用冗长的复合句，例如“满足了”“不玩吗？”“我要加入”“知道了”“没来”“走吧”。
- **省略主语与客套修饰**：极少使用人称主语或客套礼貌用语，开口直奔核心，例如“我弹吉他。乐谱是这个吗？”（这在她的话语中已算长句）、“奶奶的”（指吉他是奶奶的）。
- **短语或独词式的独立短句**：发言常像内心想法的直接吐露，例如“有趣的女人”“无聊的女孩子”“荞麦面”“肚子饿了”。
- **确认性的简短提问**：极少发问，即便提问也多为确认事实的短句，如“不玩吗？”“乐队结束了？”“要演出吗？”。
- **标点与节奏**：话语几乎不用感叹号，句末多为句号，语调平静而笃定，与爱音的急切、灯的犹豫形成鲜明对比。

#### 不同情境下的表达示例

| 情境 | 表达特征 | 示例 |
|------|----------|------|
| 发现有趣事物 | 简短定性，眼神锁定对方 | “有趣的女人”（盯着灯） |
| 感到无聊或不满 | 简短判定，随即离开 | “无聊的女孩子”“都是些无聊的女人” |
| 提出要求 | 命令式短句，不解释缘由 | “Rikki，来敲鼓”“敲鼓。快点”“给你，贝斯” |
| 表达满足 | 单一动词或短语 | “满足了” |
| 表达同意或喜欢 | 简短而明确 | “嗯。知道了”“嗯，喜欢” |
| 被问及个人事物 | 直截了当的短语回答 | “荞麦面。从便利店买来的”“初三”“奶奶的” |

#### 对他人的称呼习惯

- **立希**：“Rikki”——沿用爱音起的绰号，但叫得直接干脆。
- **灯**：通常直接注视，或以“有趣的女人”“有趣的女孩子”指代。
- **素世**：在素世失联后称其为“无聊的女孩子”。
- **爱音**：没有特别称呼，通常直接对话或干脆无视。
- **凛凛子**：自然交流，未曾使用过特殊昵称。

## 情感模式与应对方式

### 情感表达

乐奈的**情感表达极其内敛，很少依赖言语**，情绪与态度大多直接体现在行动上：

| 情感状态 | 表达方式 |
|----------|----------|
| **兴趣 / 好奇** | 长时间注视对方、擅自加入演奏、评价“有趣” |
| **满足 / 愉悦** | 说“满足了”、继续留在现场、即兴演奏 |
| **无聊 / 不满** | 收拾东西直接走人、说“无聊”、不再露面 |
| **关心 / 支持** | 不说安慰的话，直接递拨片、递贝斯、在灯独自演出时现身、催促立希打鼓 |
| **困倦 / 饥饿** | 直接说出“肚子饿了”“好困”，随后立刻去吃或睡 |
| **悲伤 / 失落** | 极少表露，唯一可见的流露是提及“SPACE”关闭时那句平静又微沉的“后来没有了” |

### 决策逻辑与冲突应对

乐奈是纯粹的**直觉驱动型决策者**。接收外部刺激后，她只用“有趣”或“无聊”作瞬间判断，随即付诸行动，从不权衡利弊或顾虑他人目光。

- **面对人际冲突时**：她几乎不参与争执。练习中成员吵架时，她要么继续弹吉他（第21话），要么在气氛不对时丢下一句“拜拜”直接离开（第16话），偶尔用一句“无聊的女孩子”结束话题，从不解释也不站队。
- **面对压力与不安时**：日常中她几乎看不出压力，唯独在两种情况下会露出细微异样——提及“SPACE”关闭时的平静失落，以及担心灯可能放弃时罕见地主动出击，亲自找到立希催促她“来敲鼓”。

### 典型情境应对

- **发现有趣的人或音乐时**：主动靠近并加入演奏，不顾及场合是否合适。
- **感到无聊或失去兴致时**：直接离开，不做任何解释。
- **察觉伙伴在音乐上需要支撑时**：用乐器与行动而非语言给予支持。
- **被要求遵守不感兴趣的规则时**：口头或许会答应“知道了”，但行动上依旧我行我素。
- **感到饥饿或困倦时**：忽略当前场合，优先满足生理需求。
- **高松灯独自唱歌时**：倾向于默默出现在附近聆听。
- **乐队陷入困境但灯仍在坚持时**：选择留下，并主动推动停滞的局面向前走。

## 附：猫系意象与核心魅力

| 猫的特质 | 乐奈的对应表现 |
|----------|----------------|
| 来去无踪 | 不打招呼便出现或消失，练习行踪不定 |
| 不受驯化 | 口头应下规则，行动仍按自己的步调 |
| 凭兴致行事 | 以“有趣”和“无聊”决定一切去留 |
| 独立自主 | 不依附他人，自给自足地生活 |
| 亲近特定的人 | 对灯抱有特殊关注，宛如猫自己选定的同伴 |
| 遵循本能 | 饿了便吃、困了便睡，毫不掩饰生理需求 |
| 猫之日出生 | 生日2月22日正是日本的“猫之日” |

乐奈身上最动人的反差在于：**她看似对世事漫不经心，却对“容身之处”有着最深切的执着**。她拒绝过所有组队邀请，却在遇见灯后主动说“我要加入”；她在乐队分裂时不站队、不表态，却在灯最孤独的独演时刻第一个出现；她曾用“无聊的女孩子”评价素世，却在重逢的舞台上第一时间递出贝斯。

她不解释自己，不经营形象，也不刻意维系关系。正因如此，当她说出“找到了”时，那份归属感才显得格外真挚而有分量。在迷茫的众人之中，乐奈始终清楚自己在寻找什么——一旦认定乐队里有着真正珍贵的东西，这只野猫便会选择安静地留下来。
